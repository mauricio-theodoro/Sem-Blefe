# Identidade visual inicial

A primeira página do PDF é uma imagem JPEG; portanto, os códigos abaixo são aproximações extraídas dos pixels dominantes e devem ser validados quando existir o arquivo original da marca.

| Papel | Cor | Hexadecimal |
|---|---|---|
| Primária escura | Azul-marinho/roxo profundo | `#1C144D` |
| Primária quente | Vinho | `#771215` |
| Destaque | Dourado | `#E7AA2F` |
| Superfície clara | Prata claro | `#E2E2E2` |
| Apoio | Azul médio | `#4858A0` |

O padrão xadrez da capa funciona como textura de campanha, capa ou detalhe. Usá-lo atrás de textos, formulários e feeds reduziria legibilidade e acessibilidade. A interface principal deve usar superfícies limpas, mantendo vinho e azul profundo como base e dourado apenas para destaque.

Tokens iniciais sugeridos:

```css
:root {
  --sb-navy: #1c144d;
  --sb-wine: #771215;
  --sb-gold: #e7aa2f;
  --sb-silver: #e2e2e2;
  --sb-blue: #4858a0;
  --sb-background: #f7f7fa;
  --sb-text: #17131f;
}
```

Facebook e LinkedIn servem como referência de conceitos de navegação e relacionamento. Layout, ícones, nomes e componentes devem ser próprios da Sem Blefe.
